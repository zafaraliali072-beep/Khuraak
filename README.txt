KHURAAK - Android app banane ke steps

1. GitHub pe naya repo banao (naam: khuraak).
2. Is folder ki SAARI files (folder ke andar ki, folder khud nahi) repo mein upload karo.
3. Repo mein build-apk.yml kholo > pencil (edit) > naam badal ke
   .github/workflows/build-apk.yml karo > Commit changes.
4. Actions tab > "Build Khuraak APK" chalega (5-10 min). Na chale to Run workflow dabao.
5. Releases > Khuraak.apk download karo aur install karo.

Update: index.html badal ke upload karo. debug.keystore ko mat hatana,
usse naya APK purane ke upar install hota hai aur data bacha rehta hai.
